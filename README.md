# 技術負債・スプリント進捗トラッカー(Notionテンプレート)

技術負債とスプリント進捗を1つのワークスペースで管理するためのNotionテンプレートです。CSVインポート形式で提供されます。

📦 購入はこちら: https://meteor01.gumroad.com/l/kvpllt

## このリポジトリについて

これは製品の紹介ページです。テンプレート本体(CSVファイル・セットアップ手順書)は購入者向けに非公開で管理されており、このリポジトリには含まれていません。仕様の確認、Star・Issueでのフィードバックにご利用ください。

## できること

・深刻度×放置期間から自動で優先度スコアを算出する数式を内蔵

・ステータス別ボード、優先度順ビュー、担当者別ビューをすぐに使える状態で提供

・スプリントごとの消化率・残り日数を自動計算

## 収録内容(製品版)

・技術負債ログ.csv — Notionにインポートする技術負債ログ

・スプリント進捗トラッカー.csv — Notionにインポートするスプリント進捗トラッカー

・セットアップ手順書.md — Notionへの導入手順
